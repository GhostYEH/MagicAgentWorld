# AgentCraft：六关玩法

最新建筑布局、知识呈现与统一任务见 [大模型中枢与 Harness 世界](05_大模型中枢与Harness世界规划.md)（v2.1：部门建筑、道路与入口已完成，教学运行联动待开发）。后续开发以该空间设计为准；本文保留上一版关卡说明。

版本：规划 v2.0。日期：2026-10-10。每章一个核心关卡，共六关，复用学园场景；教学围绕 Agent 本身。当前 C1/C2 已实现，C3—C6 为后续目标。完整体验目标约 20—30 分钟；比赛展示安排见[第四份文件](04_教学验证与参赛交付.md)。

## 一、第一章：模型觉醒

**操作：改变输入，观察输出。**

在实验台中问 AC–01 “你是谁”，移出身份记忆后重问，再恢复记忆并改问工具能力。查看三种组合的近似 Token、回答和依据；明确流畅回答不等于事实，承认未知是合理边界。

学习 Token、上下文、Prompt 和幻觉。分词器实际运行；模拟输出与真实输出分别标注。Prompt 与上下文分别修改，便于解释变量作用。

过关：指出一个输入变化及其影响，区分有依据和无依据的结论。

## 二、第二章：工具解锁

**操作：给助手安装工具。**

在工具工坊给 AC–01 安装状态查询、精确计算和知识检索。读取本次实验窗口 8192、输入 2048、预留输出 1024；实际计算剩余 5120 Token；检索工具调用规约及来源。错误参数、错误计算和空检索都产生反馈并影响核验。

过关：三个结果经引擎独立核验，且理解“检查工具回执，把有效结果带回上下文”。安装不等于执行，模型声明完成不足以证明工具成功；预算数字属于教学配置。

## 三、第三章：Agent 诞生

**操作：给出目标，让系统自主执行。**

目标是完成 Agent 运行预算诊断并生成有来源的摘要。系统自己查询配置、选择计算与检索、观察结果并决定下一步；学生查看行动链。

后续实现：把同一组工具从 C2 的玩家手动选择切换为决策器自主选择；任务配置、决策器和摘要核验需同步更新。当前旧报到引擎仅作历史回归，不作为本关完成证据。

过关：预算结果和摘要引用由独立规则核验，学生解释一次“行动—观察—下一步”。

## 四、第四章：Harness 工坊

**操作：调整运行控制。**

在同一装配台修改最大步数、必要授权、上下文/记忆和有限重试。选择一个参数做前后对照，其他参数保持不变。

增加“模型当前可见内容”抽屉，显示目标、保留的事实、近期观察和被移出的内容。日志保留与模型仍能看到信息分别展示；截止时间和输出预算放进高级设置。所有变化采用同一任务条件比较。

过关：说明参数影响，能区分模型决定、工具执行和运行约束。任务权限与实际硬预算不能靠改 Prompt 绕过。

## 五、第五章：失控与修复

**操作：看日志，修复失败。**

主示例为工具结果遗忘：计算已经成功，摘要生成却缺少结果。玩家根据回执定位遗漏，保留有来源的结果记忆或重新查询，重跑比较。

故障只移出模型可见结果，保留实际工具记录与完整日志。修复后恢复有来源的结果，再继续生成摘要；执行记录与核验同步更新。

工具误用和循环无进展作为本关可选故障，不拆成额外主线关卡。循环演示保留硬上限。

过关：提交原因、证据、修改和结果；任务通关与诊断是否正确分别评价。

## 六、最终章：智能体挑战赛

**操作：自主组装并比较方案。**

更换为不同窗口预算与资料条件的 Agent 诊断任务。玩家选择工具、记忆、权限和运行策略，不提供逐步操作答案；摘要必须能追溯到工具回执与规约来源。

比较两套配置在正常任务、暂时工具故障、有限上下文三种条件下的表现。展示合法完成数/实际测试数、步骤、游戏资源、真实调用 Token 和等待时间，缺失计量明确标注。

过关：新任务真实状态满足要求，能说明一项效率、成本或可靠性取舍。少量测试通过不能推断所有任务都可靠。

## 七、页面与布局

只做四种界面：六章任务地图、共用实验工坊、结果/配置对比、六章学习报告。C1 的输入实验台嵌入工坊，章节切换主要改变任务和可用模块。

| 工坊区域 | 内容与操作 |
| --- | --- |
| 顶部 | 当前章节、目标、模拟/真实模式、步数与资源 |
| 左侧 | 已解锁模块卡、输入与运行配置，点击安装或调整 |
| 中央 | Phaser 校园地图与助手；点击热点查看任务相关信息 |
| 右侧 | 执行时间线，展开输入、工具结果、故障证据 |
| 底部 | 开始、单步、暂停/继续、取消、重跑与查看结果 |

仅适配电脑，以 1366×768 为基准，并检查 1920×1080。地图、任务、模块、日志和配置采用 Phaser 游戏面板，中文输入采用原生控件；保留键盘与鼠标操作。每章通过移动、拾取、装配或修复形成可观察反馈。

首次体验顺序为 C1→C6，按章解锁模块；教师演示可快速跳转。每关只保留“目标—操作—反馈”三段必要提示，长文字和额外练习折叠。存档记录已过关章节和实验配置。

## 八、游戏视觉与反馈

方向：**日系动漫风的 2.5D 等距连续大世界**。地面、道路与建筑共用等距视角，人物和树木竖直，建筑有高度和基座，并产生实际前后遮挡。默认镜头贴近人物，滚轮可调整远近，M 展开等距导航总览。保留蓝瓦拱窗、樱花、Q 版探索者与机器人，以及奶油纸笺和金边 HUD。

六章分别使用实验楼、工程工坊、穹顶观测馆、钟楼控制中心、维修站、拱顶竞技馆。所有建筑共用 2:1 透视，入口朝向各自庭院；生活区补充图书馆、咖啡馆、宿舍、温室和运动场，使空间内容与区域功能对应。

世界地图用于区域定位与步行导航；区域可探索和章节机制解锁分别表示。工具执行后助手行动或地点亮起，失败时标出相关区域，修复后回放变化。徽章来自实际核验，模块采用点击安装，拖拽作为后续增强。

首版素材控制为一张校园地图、一个助手及待机/移动/成功/失败四种状态、六个章节图标、一套模块卡与状态图标、少量反馈音效。支持静音、减少动态效果；动画和音效不能阻塞单步操作。

## 九、完成标准

六关都可操作、记录和回看；输入或配置变化有可解释结果；最终任务由规则核验；学习报告显示六章证据。用目标学生实际试玩测量时长，再调整文本与提示。
