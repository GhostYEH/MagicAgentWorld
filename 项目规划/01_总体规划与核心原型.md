# AgentCraft：六章精简规划

最新空间与教学设计见 [大模型中枢与 Harness 世界](05_大模型中枢与Harness世界规划.md)（v2.1：部门建筑、道路与入口已完成，教学运行联动待开发）：中心大模型，周边 Harness 设施。本文保留 v2.0 的阶段范围记录。

版本：规划 v2.0。日期：2026-10-10。状态：第一、第二章游戏原型已实现；后四章待开发，尚未试教。按用户反馈取消报到、领卡等校园事务题材，教学直接围绕 Agent 组件。

本版按“内容精简、比赛介绍在 15 分钟以内”的要求修订。保留六章，每章一个核心关卡，共六关。四份文件分别说明总体、引擎、关卡和交付。

## 一、项目定位

面向高校 AI 初学者的交互式教育游戏。玩家培养实验伙伴 AC–01，经历“理解模型—添加工具—自主行动—配置运行环境—修复故障—综合挑战”。学园作为探索场景，学习任务直接操作模型、工具和运行控制。

目标：学生能够组装和调试一个受控智能体，并解释它为什么成功或失败。

产品形式：仅适配电脑浏览器的 Web 游戏，采用日系动漫风的 2.5D 等距连续校园。地面、道路、建筑和人物统一视角，以竖向高度、阴影和遮挡表现空间；默认角色近景，完整地图用于导航。六章位于同一片地面的六区，通过道路步行探索。技术主线为 Phaser + TypeScript + Vite，配合 Node.js/Fastify 与 SQLite。

Harness 设计参考本地 DeepSeek Harness 与 AI-Novel-Writer 源码：采用轻量运行控制、分层上下文、工具权限、预算、事件记录与恢复机制。具体映射及出处见第二份文件，本次完成设计参考，尚未集成参考项目。

## 二、六章主线

| 章节 | 核心内容 | 一个代表实验 |
| --- | --- | --- |
| 第一章：模型觉醒 | Token、上下文、Prompt、幻觉 | 装入/移出 AC–01 的记忆，比较回答和依据 |
| 第二章：工具解锁 | 查询、计算、检索 | 读取运行配置、计算 Token 预算、检索工具规约 |
| 第三章：Agent 诞生 | 拆解、选择、观察、持续执行 | 让 Agent 自主完成预算诊断并生成有来源的摘要 |
| 第四章：Harness 工坊 | 循环、权限、上下文、记忆、恢复 | 调整运行配置，观察任务结果 |
| 第五章：失控与修复 | 工具误用、循环、记忆丢失 | 根据日志修复一个故障，其他故障可切换体验 |
| 最终章：智能体挑战赛 | 自主组装、效率、成本、可靠性 | 完成新任务，比较两套配置的表现 |

六章复用一个校园世界、一套装配台和一条执行时间线，逐章解锁控制项。学生完整体验目标为约 20—30 分钟；比赛讲解与演示约 13 分钟，预留 2 分钟缓冲。

## 三、首版范围

必须完成：六个可操作关卡、模拟模式、输入/工具/执行记录、独立任务核验、配置对比、学习报告和本地演示包。

完成核心流程后接入一个真实模型。界面明确标注模拟或真实；未通过真实调用验收时，不作为已完成功能介绍。

暂缓：大型 3D、多人竞技、自由编程、多模型联赛、复杂教师后台、大规模教学研究。额外练习可以后续增加。

## 四、开发安排

| 阶段 | 建议工期 | 交付 |
| --- | --- | --- |
| 设计与原型 | 1 周 | 页面线框、统一美术样例、第一章输入与反馈原型 |
| 共享引擎 | 3—4 周 | 先打通 C1/C2，再完成循环、控制、日志与核验 |
| 六章与界面 | 3—4 周 | C3—C6、地图反馈、存档与报告；核心通过后接真实模型 |
| 验证与比赛材料 | 1—2 周 | 试玩记录、演示包、介绍材料与彩排 |

合计约 8—11 周，另留 1—2 周缓冲；按 2—3 名参与者、有稳定投入估算，实际随团队能力调整。只有部分章节完成时，标记为阶段原型。

规划已覆盖范围、六章操作、技术分工、页面与视觉、开发顺序、验收及介绍时间表。开工时先验证第一章原型，再确定最终美术素材、模型供应商与分词器；教学效果和实际比赛条款仍须验证。

## 五、验收重点

- 六章可操作，每章能看到输入或配置改变带来的结果。
- 第二章手动选工具，第三章系统自主连续行动。
- 第四章学配置，第五章依据日志诊断。
- 最终任务由世界规则核验，不能靠“模型说完成”通过。
- 报告区分游戏能量、实际 Token、时间及测试通过比例。
- 比赛彩排在 13 分钟左右完成，介绍总时长不超过 15 分钟。
